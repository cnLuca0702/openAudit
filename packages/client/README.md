# openAudit 中文审计工作台客户端

DSH 0.2.2-rc.1 审计插件的 React + TypeScript 客户端，静态入口 `/audit/`。全部业务数据来自同源、携带凭据的 `/api/audit/state` 与 `/api/audit/action`；客户端不内置模拟业务事实，也不以浏览器存储作为事实源。模拟资料由服务端分批导入，页面始终显示“演示模拟数据”。

## 构建和接入

从仓库根目录执行：

```sh
npm ci --prefix packages/client
npm --prefix packages/client run build
```

产物在 `packages/client/dist/`。Host 插件 `clientDist` 指向该目录，由 DSH 同源鉴权提供静态资源。不要把 Vite 开发服务作为公网入口。根清单、原生 DSH 菜单桥接、Host 安装与部署由协调者维护。

本地联调可执行 `AUDIT_API_ORIGIN=http://127.0.0.1:8787 npm --prefix packages/client run dev`，仅绑定回环地址；需准备实际 API 服务及其鉴权上下文。

## 页面与业务操作

- 六阶段导航采用服务端 24 个场景定义。业务按钮直接运行各场景，输入快照和运行失败由服务端保存。
- 资料中心：文件上传、来源说明、资料类别、同一版本链标识、人工派生记录、版本比较、适用版本确认、冻结工作资料集及变更留痕。
- 项目事实：核对原文、编辑金额/单位/日期及结构化业务字段，保存修订理由并产生新版本。新输入引起的影响和旧确认失效按服务端状态显示。
- 每个场景可选择具体资料版本、前序成果版本、模型辅助开关；仅展示后端已实现的可运行参数。A03 支持重点及文书包，B04/D03 支持行为日期，B09 支持目标文种，F03 支持公开范围。B06–B08 支持视觉/文本模式与视频抽帧时间。
- 专门视图包括调查主体关联、审计表、事件时间轴、跨事项明细、法规原文/官方链接/施行日期/适用条件、图纸与媒体证据、反馈与复核台账、出具前四类核验、归档三方对照和三库候选。
- 来源面板：具体文件/事实/成果、版本、定位、引用原文、解析记录来源（文件解析、人工派生、模型候选）、原件下载及下游引用。图像支持缩放和已保存像素坐标高亮，音视频保留播放器，派生转写支持实际分段回放及父原件关联。
- 原始 PDF/图像可提交真实文字识别，PDF 可选页码；原始录音可提交真实语音转写。等待和错误在来源面板直接显示，成功后打开服务端生成的待核派生资料。不会制造 OCR/转写成功或替代答案。
- 人工确认必须填写操作人、核验理由及确认声明。法规适用性另需范围说明；意见回复、落实、排除和销号分别提交，落实与销号需选择证据，服务端执行门禁。
- 成果可查看历史版本、编辑、对比、检查、人工确认及导出 Markdown/CSV/Word/Excel。阻断项、失效状态和模型错误均明确显示。
- 能力组件实际测试、脱敏/授权/范围审核、三库发布和新项目方法复用均调用服务端；不复制原项目事实。

## 浏览器验证

```sh
npm --prefix packages/client run build
npm --prefix packages/client run test:e2e
```

若环境未安装 Chromium，先执行 `npm exec --prefix packages/client -- playwright install chromium`。测试依赖完整的服务端、资料包和解析包，使用真实 `AuditService`、真实 `demo/manifest.json` 输入与磁盘状态，不模拟 API 返回值。

测试服务仅绑定 `127.0.0.1:4318`，使用 `packages/client/.test-runtime/` 中新建的独立状态目录，不访问部署实例。该测试入口为本机测试绕过 DSH 鉴权，**不用于部署，也不证明 DSH 鉴权通过**。测试产物在 `packages/client/test-results/`，HTML 报告在 `packages/client/playwright-report/`；这些运行目录已忽略。正式宿主鉴权和真实模型成功路径需由集成验收另行记录。

模型未配置的本地测试明确验证模型、OCR、ASR 失败显示和历史留存。音频分段定位测试使用显式标为人工录入的测试记录，不把它称为真实模型输出。源文件和演示输入保持不可变。

## 代码位置

- `src/App.tsx`：服务端状态、导航、资料/事实/核验/三库/历史页面。
- `src/scenario.tsx`：场景业务参数、专门成果视图和实际运行。
- `src/dialogs.tsx`：上传、版本比较、修订、确认、处置、发布和复用表单。
- `src/components.tsx`：结构化内容、来源面板、原图/媒体和键盘可用弹窗。
- `src/model.ts`：协议类型、中文字段/状态名称、带凭据的请求与错误处理。
- `tests/workbench.spec.ts`：浏览器与真实服务的端到端验证。
