# 个人审计工作台交互调整

本次按“审计人员个人使用，项目成员共用资料”重新组织 openAudit，不以组织管理驾驶舱作为首页。24 项办理功能、原件追溯、人工核验、版本失效和签发前质量控制继续使用原有业务服务。

## 个人入口与项目边界

- 首页提供审计组成员、组长/主审、业务部门复核人员、审理人员、整改检查/档案人员五类岗位推荐。岗位选择只决定推荐入口，不改变权限，不替代实际经办人或审批身份。
- 常用事项可收藏；个人工作安排可添加、勾选完成、进入关联功能和移除。个人安排是备忘，完成勾选不改变项目业务状态。
- 资料页可关注资料并筛选“我关注的资料”。岗位、收藏、关注与工作安排按项目保存在当前浏览器，不跨设备同步，不作为账号级隔离或任务分派功能。共用浏览器的人员会共享该浏览器的偏好；正式记录仍按实际经办人填写。
- 项目共用待核事项在首页折叠展示，项目办理结果明确标为项目结果，避免称为“我的待办”或“我完成的工作”。

## 工作流程与资料管理

导航按审计准备、审计实施、征求意见、复核审理、报告签发送达、整改与归档查找；进入阶段后展示具体事项、作用和项目是否已有结果。无须依次执行全部事项，支持搜索和收藏。

资料页先查找原件，再核对摘录与适用版本；提供当前资料、个人关注、待核对、已确认适用、全部历史五种范围。新版本上传可直接选择已有资料，无须记忆内部标识。上传可选中文摘录项目，金额等保留数值类型。

办理页先说明用途和所需资料，主要按钮直接说明动作。版本选择、前序成果引用、基础事实修订和智能辅助按需展开。生成结果后提示核对事实与出处，并连接文书办理台账。Word、Excel、数据表和文本稿下载标明用途。

文书台账保留被审计单位、工作节点、送达回证、质量控制、证据对应、修改留痕稿、签发用印、档案移交记录。证明材料使用复选框；表单标明选填项目；可按类型筛选记录。提供的《项目跟踪审计全流程.html》仍作为独立参考，原文、19 个节点和参考问题不写入当前项目事实。

## 用语依据与边界

主要业务名称对照审计署《中华人民共和国国家审计准则》的审计实施方案、审计证据、审计记录、审计报告编审、审计结果公布和审计整改检查等表达：
https://www.audit.gov.cn/n11/n10165075/n10165124/c10176144/content.html

用语调整不新增法律规则或期限，不将智能分析直接称为审计结论。主要对应关系：

| 原界面表达 | 调整后 |
|---|---|
| 场景、运行 | 办理事项、核对/核查/起草等具体动作 |
| 项目工作总览 | 我的工作台 |
| 资料与版本中心 | 审计资料 |
| 多模态现场取证 | 现场照片、录音与录像整理 |
| 过程资料编制与转换 | 审计取证单与工作底稿 |
| 审计质量内部控制（意见反馈功能） | 征求意见及反馈处理 |
| 三库资产 | 审计参考资料（案例、方法、参考数据） |
| 结构化字段、派生记录 | 事实明细、资料摘录 |
| 冻结资料集 | 留存资料清单 |
| 四层证据链 | 方案、证据、底稿与报告对应关系 |
| 花脸稿 | 修改留痕稿 |

原件、历史成果正文和原参考文件保持原样；新功能名称用于导航及新生成成果。系统核对通过仍需人工核验，正式复核、审理、签发和送达仍以实际办理证明为准。
