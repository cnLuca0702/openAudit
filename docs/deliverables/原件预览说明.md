# 审计资料原件预览

在“审计资料”中点击文件名或“查看原文”，PDF、DOC、DOCX、WPS、RTF、ODT 使用加宽的原件阅读面板。可翻页、按页码跳转、适合宽度或放大，并可展开“本页可读文字”复制内容。手机端按屏幕宽度显示，放大后可横向滚动。

“原文”显示文件页面，“文字摘录”保留已有解析结果。“下载原始资料”始终下载原字节，放在阅读页上方。图片、音视频原有查看方式继续可用。文档预览不代表资料真实性或适用性已获确认。

PDF 直接读取原件，扫描页不依赖 OCR。Word/WPS 在服务器内用 LibreOffice 转成 PDF 阅读副本；页面明确提示排版可能与 Word/WPS 有差异，应以原件为准。字体缺失、复杂域或旧版专有 WPS 格式可能影响预览；加密、损坏或不兼容文件显示错误并可下载另存为 DOCX/PDF 后重新上传。没有声明支持所有历史 WPS 编码。

## 部署和数据边界

- 新 DSH `/opt/dsh-v2` 使用现有 Ubuntu 22.04、LibreOffice 7.3.7.2、bubblewrap、util-linux 和中文字体；旧 DSH 不变。其他 Linux 发行版需验证系统库目录及用户命名空间权限，不允许失败后退回无隔离的 root 转换。
- 临时目录父级仅服务用户可访问；转换进入无网络、独立进程/文件系统命名空间，以 UID/GID 65534、无 capabilities 运行，只挂载系统库、字体和当前任务目录。禁用宏、关闭文档链接更新，不挂载项目数据、凭据或用户目录。
- 每次转换最多 60 秒，CPU 45 秒、地址空间 2 GiB、单文件输出 64 MiB、并行最多 2 个任务。同原件并发请求合并；成功预览按内容摘要在服务内存缓存，合计最多 64 MiB，服务重启即清空。临时任务无论成功失败均清理，输出按普通文件读取并拒绝符号链接。
- `/api/audit/preview` 沿用 DSH Cookie、Host/Origin 验证；PDF.js、worker、字符映射、字体与 WASM 均随构建部署在同源，无 CDN。浏览器不执行 PDF 内嵌脚本。下载接口仍为 attachment，上传内容不作为网页执行。
- 预览不写入项目 state、对象库或快照，不新增事实、事件、成果或确认；上传新资料仍走现有登记流程。

## 验证方式

`npm test` 包含预览鉴权、格式校验、原件不可变、缓存合并、并发上限和失败重试。`npm run test:e2e --prefix packages/client` 包含真实两页 PDF 的画布像素检查、翻页、缩放、摘录切换、手机端布局及损坏 WPS 的可恢复提示。

`scripts/verify-preview-deployed.mjs` 使用已有 DSH 登录会话，检查实际 iframe 中 PDF/DOCX 阅读；另在临时数据目录、仅回环监听的验收服务中检查 DOC/WPS/DOCX/PDF 与手机端。公开 DOC/WPS 样本来自 [深圳市龙岗区公开采购公告](https://www.lg.gov.cn/bmzz/rlzyj/xxgk/qt/tzgg/content/post_12781076.html) 附件 1、3，文件元数据显示由 WPS Office 11.8 保存；不加入项目、演示数据集或业务模型上下文。隔离验收服务结束后删除临时数据。

技术参考：[LibreOffice 命令行参数](https://help.libreoffice.org/latest/en-GB/text/shared/guide/start_parameters.html)、[PDF.js 官方示例](https://mozilla.github.io/pdf.js/examples/index.html)。
