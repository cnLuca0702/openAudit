# openAudit 演示操作指南

**演示模拟数据。** 本指南对应 DSH 0.2.2-rc.1 审计插件和 `demo/manifest.json`，用于操作准备与排练，不替代实际运行验收。模型、浏览器、宿主部署及公网入口的最终状态以协调者的验证报告和根目录部署说明为准。

## 开始前

通过协调者提供的 DSH 地址登录，在原生侧栏进入审计工作台。顶部项目应为“澄川市南岸片区雨污分流与道路更新工程”，编号 `DEMO-AUDIT-2027-006`，且显著显示“演示模拟数据”。不要使用旧 DSH 环境。

首次使用点击“导入首批演示资料”，或进入“演示管理”导入 initial。首批36份资料只含前期与现场材料、合同V1和法规；反馈、复核、整改分批开放。全部四批共57份原件、9项法规。若此前已有成果，先导出；“重置项目”需要准确输入“重置演示项目”，只用于明确要清空当前模拟项目投影的情况。

## 常规操作顺序

1. 在“资料与版本”检查原件、解析状态、来源和适用版本。点击“确认版本”填写操作者、理由；需要工作快照时再“冻结资料集”。原件保留，新版本不自动生效。
2. 在“项目事实”查看“结构化字段”和来源。数据包 records 是模拟派生输入，不代表模型已经提取成功；按原件核对后再确认。修改单位、日期或记录会生成新版本，随后重新运行相关场景。
3. 从六阶段导航进入场景，在“核查输入与运行设置”选择“人工指定文件与版本”。具体材料ID和操作见 `demo/scenario-material-map.csv`，避免把后续稿或第二项目混入当前核查。
4. 使用场景主按钮运行；若选择“调用真实模型辅助解释”，应查看实际模型与运行记录。界面会区分“规则计算，未调用模型”和“规则＋真实模型”；失败应保留错误，不能以预制文字代替。
5. 查看结果表、检查项与“引用索引”，点击来源核对具体版本、单元格、段落、图像区域或时间码。机器结果先是草案，有阻断项时不能整体确认。
6. 在“人工核验与待办”记录决定、理由和证明。反馈回复、意见落实、发现确认、整改销号分别处理；已回复不等于已落实。
7. 导出需要留存的 Markdown、JSON、CSV、Word或Excel成果，并检查模拟标识、来源和版本。五种导出是否在目标部署通过，以协调者实际报告为准。

## 三个现场变化测试

| 测试 | 操作 | 应观察到的变化 |
|---|---|---|
| 合同版本 | 初始使用 `B-CONTRACT-C01-V1`；导入review后与`B-CONTRACT-C01-V2`比较，人工决定适用版本，再运行B05 | 80%与85%条款不同；旧成果可看，相关确认及成果需复核；补充协议并非自动有效 |
| 单位映射 | B01选`B-PAYMENTS`等材料；在“项目事实”找到`PAY-061`，将51.84的单位从万元改为元，运行并查看差异，再说明理由改回万元 | 518400元与51.84元相差10000倍；变化来自实际输入；两个版本及影响记录都保留 |
| 成果范围与金额 | E01选`E-REPORT-V2`、`C-WORKPAPER`、`B-ACCEPTANCE`等；修改具体报告事实后重新执行 | 216000万元、全部管网范围、05-03与来源05-30冲突均有定位；旧确认不能继续表示新版通过 |

不要在讲解结束后悄悄还原输入。每次修正都填写理由；如需新一轮演示，按明确重置流程处理。

## 关键材料与人工步骤

**投资口径**：A02选择台账V2。48600万元概算与50200万元台账差1600万元，只是需要补核的口径差异，不能自动写成超概算。

**重复计量**：B03选择两期计量、合同、图纸及现场记录。同一 `NA-WS-01` 的0—360米和240—600米交集120米，单价1800元/米，潜在重复计量216000元。`NA-YS-02`是不同管线，即使桩号相同也不能合并。计量金额不直接等于已多付款或损失。

**冲回反例**：B05选择C03合同与流水、冲回说明。300000、-300000、300000的原付—冲回—重付链净额300000元，不能因两笔正数同额就判定重复付款。银行与账簿同一交易ID应合并来源，不能重复汇总。

**图纸**：B06点击实际SVG/PNG及区域 `[480,190,180,195]`。长度600米为模拟标注，参数确认前应保持阻止复算。管底标高未提供可靠值，不能随意补齐或将整个图纸一键判为所有参数已确认。

**盘点**：B07使用仓储台账、盘点记录、领用单和两份同内容影像。在“项目事实”核对`COUNT-PIPE`后按实际人工复点确认`confirmed`；核对`COUNT-SEAL`的50件转5箱时确认`conversionFactor=0.1`及`conversionConfirmed`。这两个标记是人工确认内容，不可仅为让表格变绿而填写。短管台账12件、已领用未出账2件、实盘10件仍需核实账务流转。

**多模态**：B08可播放12秒合成视频及51.267秒合成访谈。视频00:04—00:08展示局部沟槽示意。对音频点击“真实语音转写”会调用实际模型；人工TTS脚本不能当作ASR输出。段落边界时间码不代表逐字对齐，桩号等专业词需人工校核；所有影像均为合成材料，不能证明真实现场状态。

**意见处理**：feedback批次中的`C-TEAM-MEETING`是审计组内部讨论；review批次中的`D-REVIEW-MEETING`是业务复核会议。C02对简称、计量、投资口径分别处理；D04对具体意见检查修改位置及证据，不能用回复文本充当落实证明。

**整改**：F01先只选择要求和自报说明，再分别加入主体不符凭证和正确冲减对账凭证。第三轮是工程款冲减，不是现金到账；核对后才可人工修订相应证明事实的`offsetVerified`，不得把`bankVerified`虚填为真。具备复查条件后进入F02；后续计量反弹和未解决投资口径仍须跟踪，上传证明不自动销号。

**归档与复用**：F04有意缺少最终签发及意见落实说明，补齐也不自动关闭整改。F05候选资产经来源、脱敏、权限及适用范围确认后发布；能力组件须实际测试。第二项目`DEMO-AUDIT-2027-009`使用公里、元/公里，0—0.15与0.15—0.30仅相接，不能复制南岸项目21.6万元结论。

## 排程和失败处理

领导版25—30分钟建议按“资料全景5、一张表4、计量合同6、报告审核6、整改复用4、互动3”安排。审计人员完整版60—90分钟建议80分钟，覆盖全部24场景，详细排程见V3方案。以上是预算，不是已测效率承诺。

缺文件时补入正确批次或选择具体版本；没有来源时保持待核；模型失败时查看“运行记录”并检查配置与输入，不改写成成功。导出或解析异常应保留原件和错误。最终验收填写`demo/acceptance-checklist.csv`的实际结果与证据路径，不能把预期列直接复制成已通过。

材料再生成、目录结构、法条来源、字体依赖、TTS复现边界见`demo/README.md`。测试真值位于`demo/truth/`，仅测试人员读取，严禁上传或加入业务模型上下文。
